# AI-Retail-Behavioral-Surveillance-Pipeline

Multi-stage computer vision pipeline (detect, track, pose estimation, behavior analysis, risk scoring) for automated retail surveillance and anomaly detection.

## Features
- Object detection and multi-object tracking
- Pose estimation feeding into behavior analysis
- Risk scoring for anomaly/behavioral flags

## Tech Stack
OpenCV, PyTorch, Vision Transformers / CNNs

## Setup & Run
1. `pip install -r requirements.txt`
2. Point `config.yaml` at your video source (file or RTSP stream).
3. Run `python pipeline.py` to process the stream through detect → track → pose → behavior → risk stages.
